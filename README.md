
# 🧊 Онлайн Чат на PyWebIO

Простой веб-чат с обновлением в реальном времени на Python.

---

## ✨ Возможности
✅ Асинхронное обновление сообщений

✅ Уведомления о входе/выходе

✅ Несколько пользователей одновременно

✅ Автоочистка старых сообщений (100 шт)

✅ Адаптивный интерфейс

## 📝 Как работает
Вход — ввод уникального ника

Сообщения — отправка и отображение у всех

Обновление — фоновая проверка новых сообщений

Выход — удаление из списка онлайн

## ⚙️ Настройка
В коде можно изменить:

```
PORT = 8080               
MAX_MESSAGES_COUNT = 100    
DEBUG = True
